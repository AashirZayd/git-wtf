What's going on
  🔴 Your branch has diverged AND your working tree has changes.

  You have 2 local commits and the remote has 1 commit you don't have.
  Working tree: 1 staged, 1 modified, 1 untracked.
  Rebase or pull may be blocked by your uncommitted changes.

Suggested next step
  → Review or stash your working changes before reconciling history.

  $ git stash
  $ git log --oneline --left-right HEAD...@{upstream}
The Problem

Git gives you the pieces.
You still have to figure out the puzzle.

git status gives you raw file lists and status codes. But real repositories have interacting states that cause confusion and mistaken commands.

git status

State

Dumps independent counters and flags without contextual interpretation:

  • ✕ Shows ahead and behind as raw numbers
  • ✕ Reports modified files regardless of divergence
  • ✕ Leaves conflict interactions to manual deduction
  • ✕ Provokes hasty or destructive reset commands

git-wtf

Interpretation

Explains what the combination actually means before you act:

  • ✓ Reasons about combined states (diverged + dirty tree)
  • ✓ Identifies why pulling or rebasing would fail
  • ✓ Recommends safe inspection before altering history
  • ✓ Works completely offline without mutating files

Design Principles

Why git-wtf

Built for developers who value focused, reliable, and lightweight command-line tools.

01

Human-Readable

No obscure porcelain codes to decipher. Clear visual indicators and plain-English explanations.

02

Context-Aware

Analyzes combinations of branch divergence, stashes, operations, and working tree changes together.

03

Strictly Read-Only

It can suggest commands. It never executes write operations, resets, or checkout operations.

04

100% Offline

Zero network calls. Remote tracking calculations reflect local refs without making server requests.

05

Machine-Readable

Full --json mode emitting unstyled, pure JSON for editor plugins, CI scripts, and automation.

06

Dependency-Light

A tiny, focused CLI (~14 kB compressed) instead of a massive, bloated developer framework.

Installation

Install git-wtf

Build and link from source in seconds. Works everywhere Git and Node.js are available.

git clone <repository-url> cd git-wtf npm install npm run build npm link

Supported Options

Option Shorthand Description
--json -j Output unstyled, structured JSON for automation
--verbose -v Show grouped changed file lists and recent commits
--help -h Display help and usage examples
--version -V Show current version (0.1.0)
Trust & Safety

Your repository stays yours.

Designed from day one to be safe to run anywhere without side effects or surprises.

Read-Only

Zero Mutating Actions

It never commits, rebases, merges, checks out, resets, or stashes automatically.

Offline

Zero Remote Calls

No network calls. Ahead/behind values reflect your locally fetched tracking refs.

Private

Zero Telemetry

No analytics trackers, no telemetry beacons, no cloud logging, no data collection.

Secure

Safe Process Spawns

Invokes Git using direct argument arrays. Filenames cannot inject arbitrary shell syntax.
